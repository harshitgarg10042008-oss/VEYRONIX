# ConfigSentinel AI logo asset review

The merged asset set contains a full lockup and an emblem mark. The full lockup uses a deep graphite background, a metallic silver shield/sentinel emblem, electric-blue circular orbit and accents, the exact visible product name `CONFIGSENTINEL AI`, the tagline `EVIDENCE. CONTROL. SECURITY.`, and secondary attribution `BY VEYRONIX`.

The emblem-only file is visually suitable as a compact mark but is stored with a checkerboard-like background baked into the image rather than a true alpha channel. For the dashboard rail, the dark full-lockup treatment is safer against the graphite sidebar; use the emblem only where the surrounding container controls contrast. The files have `.png` names but are encoded as JPEG images, so browsers should be tested against the deployed/static serving path.
