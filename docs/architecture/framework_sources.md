# Framework source notes

The expanded registry uses official landing pages and labels mappings as informative until organization-specific assessor validation:

- NIST Cybersecurity Framework 2.0: https://www.nist.gov/cyberframework
- PCI Security Standards Council document library and PCI DSS: https://www.pcisecuritystandards.org/document_library/ and https://www.pcisecuritystandards.org/standards/pci-dss/
- ISO/IEC 27001:2022 public browse entry: https://www.iso.org/obp/ui/#iso:std:iso-iec:27001:ed-3:v1:en
- HHS HIPAA Security Rule overview: https://www.hhs.gov/hipaa/for-professionals/security/laws-regulations/index.html
- AICPA SOC information: https://www.aicpa-cima.com/topic/audit-assurance/soc

Registry entries identify the source and version context; they do not claim certification or replace a formal assessor crosswalk.
