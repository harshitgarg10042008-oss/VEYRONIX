Trust and Safety
by Design

Deterministic Authority

Compliance verdicts are derived from hard-coded control logic and parser evidence, not probabilistic model guesses.

LLM Trust Boundary

Inputs are redacted and hashed; outputs are schema-validated. The LLM assists interpretation but never decides alone.

Fail-Closed Semantics

Unknown syntax or parser ambiguity results in a "REVIEW REQUIRED" status, never a silent pass.

No Excessive Agency

The system generates non-executable previews. It has no path to connect to or modify live network devices.
